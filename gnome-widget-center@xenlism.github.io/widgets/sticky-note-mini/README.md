# Sticky Note (Mini)

`1x1` version of `sticky-note` - same classic Mac OS X **Stickies**
look (colored paper, folded page-curl corner, click-anywhere-to-write),
scaled down to fit a single grid cell: tighter padding, a smaller
fold/color-dot, and a smaller default type size so a line of text
still fits.

## Behavior

Identical to the full-size `sticky-note` widget - see its README for
the click-to-edit dialog, color-cycle dot, and folded-corner details.
The only differences here are the smaller default sizes above, all of
which stay adjustable from the **Sticky Note** settings tab.

## Settings (Sticky Note tab)

- **Paper**: paper color, corner radius, show/hide the folded corner,
  show/hide the color-cycle dot.
- **Text**: placeholder text, font, text color, alignment (left/center).
- **Shadow**: standard drop-shadow tab shared by all widgets.
