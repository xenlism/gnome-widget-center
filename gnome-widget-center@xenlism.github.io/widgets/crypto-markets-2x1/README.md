# Crypto Markets (2x1)

2x1 card: header with coin tabs, live price, 24h change pill, line graph and footer.
Data: CoinGecko (no key, includes 7-day hourly graph) or CoinMarketCap (API key).

- Coins: list of symbols (`BTC`, `ETH`, ...). Unknown coins: `SYMBOL:coingecko-id`, e.g. `KAS:kaspa`.
- Click a tab to switch coin; optional auto-rotate.
- Graph: line color (follow trend or custom), width, smooth, fill, range 24h / 7d.
- Refresh: 30 s - 1 h (CoinGecko free tier may throttle under 60 s).
- Card settings (background, corner radius, blur, shadow, border, opacity) come from the shared Appearance tab.
