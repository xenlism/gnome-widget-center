# Geek Date Stat (Big)

Large `4x1` card (47×11 grid cells) with two centered lines:

```
          02 AUGUST 2026

     CPU 100%  MEM 100%  DISK 100%
```

Same widget as **Geek Date Stat (Bar)**, just sized for the bigger `4x1`
block-type with larger default fonts/padding/corner-radius. See that
widget's README for the full settings list (date text, system text, card
background, text shadow, widget shadow) — every setting name and behavior
is identical between the two.
